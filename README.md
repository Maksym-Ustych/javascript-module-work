# Підсумкова модульна робота з JavaScript

## Дисципліна
Основи програмування мовою JavaScript

## Опис
Проєкт містить практичні завдання з:
- змінних і типів даних;
- умовних операторів;
- циклів;
- функцій;
- масивів;
- об’єктів;
- async/await;
- замикань;
- DOM;
- класів та ООП.

## Структура проєкту
- task1.js — змінні, цикли, функції
- task2.js — масиви та функції вищого порядку
- task3.js — async/await та API
- task4.js — класи, ООП та DOM

## Запуск проєкту
Відкрити проєкт у Visual Studio Code та запустити через Live Server.
